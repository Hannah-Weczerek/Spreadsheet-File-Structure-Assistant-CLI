# Spreadsheet-File-Structure-Assistant-CLI
A tool for automating the process of converting a spreadsheet file (.xlsx .odt etc.) to a file structure tree with automated data.txt for datasets per entry. Available and tested for / on Linux, Windows 10, Windows 11. ARM compatibility unknown, probably not without compatibility / translation layer. The tool is available as a portable version, i.e. it does not need to be installed. It does not require internet and does not automatically update. Every copy is contained in it's own folder. .NET is included, no installation required.

# Spreadsheet-File-Structure-Assistant-CLI
Ein Tool zum automatisierten Auslesen von Spreadsheets, z.B. .xlsx .odt und co. Kompatibel mit Windows 10, Windows 11 und gängigen Linux-Distributionen. Das Tool liegt portabel vor. Es muss nicht installiert werden und bündelt .NET bereits in sich.
